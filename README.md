# VIVA+

Projeto VIVA+ — plataforma de organização pessoal, finanças e economia.

Identidade visual: roxo saturado `#7028D8`, amarelo `#FFD43B` e branco acinzentado `#F4F3F6`.

Aplicação Next.js preparada para deploy na Vercel. Configure as variáveis do Supabase conforme `.env.example` e execute a migração em `supabase/migrations/`.
